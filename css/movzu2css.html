HTML və CSS Əlaqəsi: CSS Selektorları

CSS-in əsas məqsədi HTML elementlərini bəzəməkdir. Lakin dizayn verməzdən əvvəl brauzerə səhifədəki hansı elementi dəyişmək istədiyimizi dəqiq bildirməliyik. Məhz bu məqsədlə **CSS Selektorlarından (Selectors)** istifadə olunur. Selektorlar HTML teqlərini hədəf almaq üçün istifadə edilən xüsusi ifadələrdir.

Əsas Təməl CSS Selektorları

Veb proqramlaşdırmada ən çox istifadə olunan 5 əsas selektor növü var:

1. Universal Selektor (*)

Səhifədəki **bütün** HTML elementlərini eyni anda seçmək üçün istifadə olunur. Ulduz (*) simvolu ilə yazılır. Adətən bütün elementlərin kənar boşluqlarını sıfırlamaq üçün layihənin ən başında istifadə edilir. 

                * {
                margin: 0;
                padding: 0;
                }

2. Element Selektoru (Teqin adına görə)

HTML teqinin birbaşa öz adını yazaraq həmin növdən olan bütün elementləri hədəf alır. Məsələn, səhifədəki bütün paraqrafları və ya bütün başlıqları seçmək üçün: 

                    h2 {
                    color: green;
                    }

Bu kod səhifədəki istisnasız hər bir <h2> teqini yaşıl rəngə boyayacaq.

3. Class (Sinif) Selektoru (.)

HTML-də xüsusi qruplar yaratmaq üçün elementlərə class atributu verilir. CSS-də bu sinifləri seçmək üçün adın qarşısına **nöqtə (.)** simvolu qoyulur. Class selektoru çoxlu istifadə üçün idealdır, yəni eyni class adını bir çox HTML teqinə vermək olar. 

                .mavi-metn {
                color: blue;
                }

HTML tərəfdə istifadəsi: <p class="mavi-metn">Bu mətn göydür.</p>

4. ID Selektoru (#)

Səhifədə yalnız **bir unikal (tək)** elementi seçmək üçün elementə id atributu verilir. CSS-də ID-ni hədəf almaq üçün adın qarşısına **diyez (#)** simvolu qoyulur. Eyni ID adı bir HTML sənədində yalnız bir dəfə işlədilə bilər. 

                #esas-basliq {
                font-size: 40px;
                text-align: center;
                }

HTML tərəfdə istifadəsi: <h1 id="esas-basliq">Xoş Gəlmisiniz!</h1>

5. Qruplaşdırma (Grouping) Selektoru

Əgər fərqli elementlərə tamamilə eyni dizaynı vermək istəyirsinizsə, hər birini ayrı-ayrı yazmaq yerinə, aralarına **vergül (,)** qoyaraq kodları birləşdirə bilərsiniz. Bu, kodun təkrar olunmasının qarşısını alır. 

                h1, h2, p {
                font-family: sans-serif;
                color: #333;
                }

Selektorların Müqayisə Cədvəli

Selektorların yazılış sintaksisi və tətbiq sahələrinin xülasəsi:

Selektor Növü CSS-də Sintaksisi HTML Nümunəsi Seçim Sahəsi
Universal * { ... } Bütün teqlər Səhifədəki hər şey
Element p { ... } <p>Mətn</p> Bütün <p> teqləri
Class (Sinif) .qirmizi { ... } <div class="qirmizi"> Həmin klası daşıyan hər kəs
ID (Unikal) #unikal-blok { ... } <section id="unikal-blok"> Yalnız həmin xüsusi element
Qruplaşdırma h1, .test { ... } Fərqli teqlər Siyahıdakı elementlərin hamısı

Tam Kod Nümunəsi

Bütün bu selektorların bir arada işləmə formasına baxaq:

                <!DOCTYPE html>
                <html lang="az">
                <head>
                    <style>
                        /* Element Selektoru */
                        body { background-color: #fafafa; }
                        
                        /* ID Selektoru */
                        #ust-panel { background-color: #eee; padding: 10px; }
                        
                        /* Class Selektoru */
                        .diqqet-metni { color: red; font-weight: bold; }
                        
                        /* Qruplaşdırma Selektoru */
                        h1, h2 { color: rgb(92, 92, 227); }
                    </style>
                </head>
                <body>

                    <div id="ust-panel">
                        <h1>Veb Proqramlaşdırma Bloqu</h1>
                    </div>

                    <h2>CSS dərsləri sürətlə davam edir</h2>
                    <p class="diqqet-metni">Xəbərdarlıq: ID adlarını eyni səhifədə təkrarlamayın!</p>

                </body>
                </html>

Nəticə

CSS Selektorlarını düzgün qura bilmək təmiz və effektiv kod yazmağın əsasıdır. Class və ID arasındakı fərqi anlamaq çox vacibdir: Class bir formadır və onu istənilən sayda elementə geyindirə bilərsiniz, ID isə elementin şəxsiyyət vəsiqəsidir — təkrarsız və tək olmalıdır. Növbəti dərsimizdə rənglərin təyini və arxa fon dizaynlarını öyrənəcəyik.
