CSS Giriş

HTML veb səhifənin skeletini və strukturunu yaradır, lakin ona vizual gözəllik, rəng, nizamlı düzülüş və dizayn vermək üçün bizə mütləq CSS lazımdır. CSS öyrənməklə siz veb səhifələrinizi tamamilə dəyişdirə və onları modern üsluba sala bilərsiniz.

CSS Nədir?

CSS (Cascading Style Sheets) — veb səhifələrin görünüşünü tənzimləmək üçün istifadə olunan bir üslub (stil) dilidir. O, HTML elementlərinin ekranda, kağızda və ya digər media vasitələrində necə göstərilməli olduğunu təyin edir.

CSS-in əsas vəzifələri:

  • Mətnlərin rəngini, şriftini (font) və ölçüsünü dəyişmək.
  • Elementlərin səhifədəki yerini (Layout) müəyyən etmək (böyüklük, kənar boşluqlar və s.).
  • Saytların mobil telefonlara, planşetlərə və kompüter ekranlarına uyğunlaşmasını (Responsive dizayn) təmin etmək.
  • Eyni dizaynı bir neçə HTML səhifəsinə eyni anda tətbiq etməklə vaxta qənaət etmək.

CSS Sintaksisi (Yazılış Qaydası)

CSS kodu çox sadə bir qayda üzərində qurulur. O, bir Selektor (Selector) və bir Bəyannamə bloqundan (Declaration block) ibarətdir: 

                selector {
                property: value;
                }

Burada hər bir hissənin öz mənası var:

  • Selector (Selektor): Stil vermək istədiyiniz HTML elementini seçir (Məsələn: h1, p, div).
  • Property (Xüsusiyyət): Dəyişmək istədiyiniz stil növüdür (Məsələn: color, font-size, background-color).
  • Value (Dəyər): Xüsusiyyətə verdiyiniz yeni tənzimləmədir (Məsələn: red, 20px, blue).

Nümunə:

                p {
                color: red;
                font-size: 16px;
                }

Bu kod səhifədəki bütün paraqrafların (<p>) mətn rəngini qırmızı, şrift ölçüsünü isə 16 piksel edəcək.

HTML Sənədinə CSS Əlavə Etməyin 3 Üsulu

CSS kodlarını HTML səhifəsinə bərkitmək üçün üç fərqli metod mövcuddur:

Metodun Adı Yazılış Yeri Nümunə Kod
Inline (Daxili / Sətiriçi) Birbaşa HTML teqinin içində style atributu ilə yazılır. <h1 style="color:blue;">Başlıq</h1>
Internal (Daxili Sənəd) HTML sənədinin <head> hissəsində <style> teqləri arasında yazılır. 
                    <style>
                    body { background-color: text; }
                    </style>
External (Xarici Fayl) Ayrıca bir `.css` faylı yaradılır və HTML-ə <link> teqi ilə qoşulur. <link rel="stylesheet" href="style.css">

> **Qeyd:** Real layihələrdə və böyük saytlarda kodların təmiz və nizamlı olması üçün hər zaman **External (Xarici) CSS** üsulundan istifadə olunması tövsiyə edilir.

Tam Bir CSS-HTML Nümunəsi

Aşağıda CSS teqlərinin HTML daxilində (Internal üsulla) istifadəsinə aid sadə bir nümunə verilmişdir:

                    <!DOCTYPE html>
                    <html lang="az">
                    <head>
                        <meta charset="UTF-8">
                        <title>CSS İlk Səhifəm</title>
                        <style>
                            body {
                                background-color: #f0f0f0;
                            }
                            h1 {
                                color: darkblue;
                                text-align: center;
                            }
                            p {
                                font-family: Arial;
                                font-size: 18px;
                                color: #333;
                            }
                        </style>
                    </head>
                    <body>

                        <h1>CSS Dünyasına Xoş Gəlmisiniz!</h1>
                        <p>Bu paraqraf CSS vasitəsilə dizayn edilmişdir.</p>

                    </body>
                    </html>

Nəticə

CSS veb proqramlaşdırmanın vizual tərəfidir. O olmasaydı, internetdəki bütün saytlar sadə qara mətndən və ağ arxa fondan ibarət olardı. CSS-in təməl qaydalarını və HTML-ə qoşulma üsullarını öyrənməklə siz veb dizaynerlik yolunda ən böyük addımı atmış olursunuz. Növbəti dərslərdə teqləri daha dəqiq seçmək üçün xüsusi selektorları öyrənəcəyik.
