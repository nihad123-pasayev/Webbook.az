CSS ilə Mətnlərə Üslub Təyini

Veb səhifədəki məzmunun böyük hissəsini mətnlər təşkil edir. Bu mətnlərin oxunaqlı, estetik və nizamlı görünməsi istifadəçi təcrübəsi üçün çox vacibdir. CSS-də mətnlərin rəngini, ölçüsünü, düzləndirilməsini və şrift (font) ailəsini idarə etmək üçün xüsusi xüsusiyyətlər (properties) mövcuddur.

Əsas Mətn Xüsusiyyətləri

1. Mətnin Rəngi (color)

Mətnin rəngini təyin etmək üçün color xüsusiyyətindən istifadə olunur. Rənglər adla (blue), HEX kodu ilə (#5c5ce3) və ya RGB formatı ilə (rgb(92, 92, 227)) verilə bilər. 

                    p {
                    color: #333333;
                    }

2. Mətnin Düzləndirilməsi (text-align)

Mətni üfüqi istiqamətdə düzləndirmək üçün istifadə olunur. Alacağı əsas dəyərlər:

  • left: Mətni sola çəkir (standart hal).
  • right: Mətni sağa çəkir.
  • center: Mətni mərkəzə mərkəzləşdirir (başlıqlar üçün çox istifadə olunur).
  • justify: Mətni hər iki tərəfə bərabər yayır (kitab və qəzet səhifələrindəki kimi).
                h1 {
                text-align: center;
                }

3. Mətnin Dekorasiyası (text-decoration)

Mətnə alt xətt, üst xətt əlavə etmək və ya mövcud xətləri silmək üçün işlədilir. Ən çox linklərin (<a> teqinin) altındakı xətti silmək üçün none dəyəri ilə istifadə olunur:

  • underline: Altından xətt çəkir.
  • line-through: Üzərindən xətt çəkir.
  • none: Bütün xətləri silir.
                a {
                text-decoration: none;
                }

4. Böyük-Kiçik Hərf Transformasiyası (text-transform)

Mətndəki hərflərin HTML koduna toxunmadan böyük və ya kiçik hərflərlə yazılmasını tənzimləyir:

  • uppercase: Bütün mətn bütövlüklə böyük hərflərlə yazılır.
  • lowercase: Bütün mətn kiçik hərflərlə yazılır.
  • capitalize: Hər sözün yalnız ilk hərfi böyük açılır.

Şrift (Font) Xüsusiyyətləri

Mətnin formasına və ölçüsünə birbaşa təsir edən font tənzimləmələri aşağıdakılardır:

1. Font Ailəsi (font-family)

Mətnin hansı yazı üslubunda (şriftdə) görünəcəyini təyin edir. Ekranda problem çıxmaması üçün adətən bir neçə şrift adı ardıcıl yazılır (əgər birincisi kompüterdə yoxdursa, brauzer ikincini işlədir): 

                p {
                font-family: Arial, Helvetica, sans-serif;
                }

2. Font Ölçüsü (font-size)

Mətnin böyüklüyünü təyin edir. Ən çox istifadə olunan ölçü vahidi px (piksel) və rem formatlarıdır. 

                .metn-boyuk {
                font-size: 20px;
                }

3. Font Qalınlığı (font-weight)

Mətnin incə və ya qalın olmasını təyin edir. normal, bold dəyərlərini və ya 100-900 arası rəqəmsal dəyərləri ala bilər (məsələn, 400 normal, 700 bold deməkdir).

Mətn Üslubları Xülasə Cədvəli

CSS Xüsusiyyəti Tez-tez İstifadə Olunan Dəyərlər Təyinatı
color red, #ffffff, rgb(0,0,0) Mətnin rəngini təyin edir.
text-align left, right, center, justify Mətni üfüqi istiqamətdə düzləndirir.
text-decoration none, underline, line-through Mətnə xətt effektləri verir və ya silir.
text-transform uppercase, lowercase, capitalize Hərflərin böyük/kiçikliyini dəyişir.
font-family Arial, Tahoma, sans-serif Mətnin yazı stilini (şriftini) seçir.
font-size 14px, 1.2rem, 18px Şriftin ekrandakı ölçüsünü təyin edir.
font-weight normal, bold, 400, 700 Mətnin qalınlıq dərəcəsini nizamlayır.

Praktik Kod Nümunəsi

Aşağıdakı nümunədə mətn teqlərinin CSS vasitəsilə necə fərqli şəkillərə salındığını görə bilərsiniz:

                <!DOCTYPE html>
                <html lang="az">
                <head>
                    <style>
                        h1 {
                            font-family: 'Times New Roman', serif;
                            font-size: 36px;
                            color: rgb(92, 92, 227);
                            text-align: center;
                            text-transform: uppercase;
                        }
                        
                        .anons-metn {
                            font-family: Arial, sans-serif;
                            font-size: 16px;
                            line-height: 1.5; /* Sətirlərarası boşluq */
                            text-align: justify;
                        }

                        .silinmis-qiymet {
                            color: gray;
                            text-decoration: line-through;
                        }
                    </style>
                </head>
                <body>

                    <h1>Kompüter elmləri</h1>
                    <p class="anons-metn">Mətn üslubları saytın oxunma keyfiyyətini artırır.</p>
                    <p>Köhnə qiymət: <span class="silinmis-qiymet">100 AZN</span></p>

                </body>
                </html>

Nəticə

Mətnlərin düzgün formatlanması veb layihələrin vizual zənginliyini tamamlayır. CSS-də font və text xüsusiyyətlərini kombinasiya edərək istənilən yazı tipini oxuyucu üçün cəlbedici formaya gətirmək mümkündür. Növbəti dərslərimizdə veb elementlərinin blok quruluşunu (Box Model) və kənar boşluqları öyrənəcəyik.
