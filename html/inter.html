HTML Giriş

HTML nədir?

HTML (HyperText Markup Language) veb səhifələrin yaradılması üçün istifadə olunan əsas işarələmə dilidir. İnternetdə gördüyümüz demək olar ki, bütün veb səhifələr HTML vasitəsilə qurulur.

HTML proqramlaşdırma dili deyil. O, brauzerə məzmunun necə göstərilməli olduğunu bildirən işarələrdən (taglardan) ibarətdir.

HTML ilə aşağıdakı elementləri yaratmaq mümkündür:

  • Başlıqlar
  • Paraqraflar
  • Şəkillər
  • Keçidlər (linklər)
  • Cədvəllər
  • Siyahılar
  • Formalar
  • Videolar və audiolar

HTML Necə İşləyir?

HTML sənədi müxtəlif taglardan ibarət olur. Bu taglar brauzerə məzmunun strukturunu bildirir.

Məsələn:

                <h1>Salam Dünya</h1>
                <p>Bu mənim ilk HTML səhifəmdir.</p>

Burada:

  • <h1> əsas başlıq yaradır.
  • <p> paraqraf yaradır.
  • Açılış tagı (<h1>) və bağlanış tagı (</h1>) arasında yazılan mətn ekranda göstərilir.

Sadə HTML Sənədinin Quruluşu

Hər HTML səhifəsi müəyyən bir quruluşa malik olur.

                <!DOCTYPE html>
                <html>
                <head>
                    <title>Mənim Saytım</title>
                </head>
                <body>

                    <h1>Salam Dünya</h1>
                    <p>Bu ilk HTML səhifəmdir.</p>

                </body>
                </html>

Bu sənəddə:

Element Təyinatı
<!DOCTYPE html> Sənədin HTML5 olduğunu bildirir
<html> HTML sənədinin başlanğıcıdır
<head> Səhifə haqqında məlumatları saxlayır
<title> Brauzer tabında görünən başlıqdır
<body> İstifadəçinin gördüyü bütün məzmunu saxlayır

HTML Tagları

HTML tagları adətən bu formada yazılır:

                <tagname>Məzmun</tagname>

Nümunə:

                <p>Bu bir paraqrafdır.</p>

Əksər tagların açılış və bağlanış hissəsi olur.

Lakin bəzi taglar bağlanış tagı olmadan da istifadə edilə bilər.

Məsələn:

                <br>
                <hr>
                <img>

HTML Elementi Nədir?

HTML elementi açılış tagı, məzmun və bağlanış tagından ibarət olur.

Nümunə:

                <p>Salam Dünya</p>

Bu elementin hissələri:

  • Açılış tagı → <p>
  • Məzmun → Salam Dünya
  • Bağlanış tagı → </p>

HTML Atributları

Atributlar element haqqında əlavə məlumat verir.

Nümunə:

                <a href="https://example.com">Sayta keç</a>

Burada:

  • href atributdur.
  • Atributun dəyəri "https://example.com" hissəsidir.

Başqa nümunə:

                <img src="image.jpg" alt="Şəkil">

Burada:

  • src şəklin ünvanını göstərir.
  • alt şəkil yüklənmədikdə görünən mətndir.

HTML Faylı Necə Yaradılır?

  1. İstənilən mətn redaktoru açın.
  2. Yeni fayl yaradın.
  3. HTML kodlarını yazın.
  4. Faylı .html uzantısı ilə saxlayın.
  5. Faylı brauzerdə açın.

Nümunə:

                index.html
                about.html
                contact.html

HTML-in Üstünlükləri

HTML-in əsas üstünlükləri:

  • Öyrənilməsi asandır.
  • Pulsuzdur.
  • Bütün brauzerlər tərəfindən dəstəklənir.
  • CSS və JavaScript ilə birlikdə işləyir.
  • Müasir veb saytların əsasını təşkil edir.

HTML, CSS və JavaScript Arasındakı Fərq

Veb inkişafında adətən bu üç texnologiya birlikdə istifadə olunur.

Texnologiya Vəzifəsi
HTML Struktur yaradır
CSS Dizayn və görünüş yaradır
JavaScript İnteraktivlik əlavə edir

Məsələn:

  • HTML evin skeletidir.
  • CSS evin rənglənməsi və dekorasiyasıdır.
  • JavaScript isə evdəki elektrik sistemidir.

Nəticə

HTML veb inkişafının əsasını təşkil edən işarələmə dilidir. Veb səhifənin strukturu HTML vasitəsilə qurulur, dizayn CSS ilə hazırlanır, funksionallıq isə JavaScript vasitəsilə əlavə edilir. HTML öyrənmək veb proqramlaşdırmaya başlamaq üçün ilk və ən vacib addımdır.
