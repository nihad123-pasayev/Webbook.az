Əsas Struktur Elementləri və İzahatı

<!DOCTYPE html>

DOCTYPE teqi HTML sənədinin hansı versiyada yazıldığını göstərir. HTML5-də bu sadə şəkildə yazılır: <!DOCTYPE html>. Bu teq brauzerə bildirir ki, səhifə ən yeni HTML standartlarına uyğun işlənməlidir. Əgər bu bəyannamə yazılmazsa, brauzer səhifəni köhnə rejimdə ("Quirks mode") göstərə bilər və bu da dizayn və vizual görünüş problemlərinə səbəb ola bilər.

<html>

<html> teqi HTML sənədinin əsas kök (root) elementidir. Yəni bütün digər teqlər bu elementin daxilində yerləşir. Səhifənin başlanğıcı və sonu bu teq ilə müəyyən edilir. HTML sənədində yazılan hər şey <html> teqinin içində olmalıdır. Adətən bura axtarış motorları üçün lang="az" atributu əlavə edilir.

<head>

Head hissəsi səhifənin görünməyən, amma vacib texniki məlumatlarını (metadata) saxlayan bölmədir. Burada səhifənin kodlaşdırması (Azərbaycan şriftlərinin düzgün görünməsi üçün <meta charset="UTF-8">), CSS fayllarına bağlantılar, mobil uyğunluq tənzimləmələri yerləşir. İstifadəçi bu hissəni səhifənin içində görmür, amma brauzer səhifəni düzgün emal etmək üçün bu məlumatlardan istifadə edir.

<title>

Title teqi səhifənin adını müəyyən edir. Bu ad brauzerin yuxarı hissəsində (tab hissəsində) və Google axtarış nəticələrində əsas başlıq kimi görünür. Məsələn, bir sayt açdıqda orada yazılan başlıq məhz <title> teqi ilə təyin olunur. Bu həm istifadəçi təcrübəsi, həm də SEO üçün çox vacibdir.

<body>

Body hissəsi istifadəçinin ekranda gördüyü bütün vizual məzmunun yerləşdiyi əsas sahədir. Burada mətnlər, şəkillər, linklər, düymələr, cədvəllər və digər elementlər olur. Saytın bütün görünən və interaktiv hissəsi məhz bu bölmədə yaradılır.

Struktur Elementlərinin Xülasəsi

Elementlərin funksiyalarını daha yaxşı yaddan çıxarmamaq üçün aşağıdakı cədvəldən istifadə edə bilərsiniz:

Element Görünüş Yeri Əsas Təyinatı
<!DOCTYPE html> Görünmür Sənədin müasir HTML5 standartında olduğunu bəyan edir.
<html> Görünmür Bütün səhifə kodlarını əhatə edən əsas kök elementdir.
<head> Görünmür Səhifənin texniki sazlamalarını və meta məlumatlarını saxlayır.
<title> Brauzer Tabında Səhifənin rəsmi adını təyin edir (SEO üçün kritikdir).
<body> Veb Səhifədə İstifadəçiyə görünən bütün vizual elementləri özündə birləşdirir.

Sadə HTML Sənəd Nümunəsi

Standart bir HTML səhifəsinin kod iyerarxiyası aşağıdakı qaydada qurulur:

                <!DOCTYPE html>
                <html lang="az">

                <head>
                    <meta charset="UTF-8">
                    <title>Mənim İlk Səhifəm</title>
                </head>

                <body>
                    <h1>Salam Dünya!</h1>
                    <p>Bu HTML sənədinin sadə nümunəsidir.</p>
                </body>

                </html>

Nəticə

Nəticə olaraq, HTML sənədinin strukturu strukturlaşdırılmış veb proqramlaşdırmanın təməlidir. Bu əsas elementləri düzgün anlamaq və tətbiq etmək veb mütəxəssisi olmağın ilk və ən mühüm addımıdır. Demək olar ki, internetdəki bütün saytlar məhz bu sadə və məntiqi struktur üzərində qurulur.
